An ultra-modern, responsive developer portfolio showcasing full-stack web applications, REST microservices, machine learning pipelines, and web automation systems built by **Muhammad Bilal Farid**.

---

## 🚀 Key Features

- **Hero Section**: Dynamic animated role typing, GitHub & Email CTAs, floating tech badges.
- **Interactive Project Gallery**: Real-time category filtering (`Full-Stack`, `Backend & APIs`, `Machine Learning`, `Automation`) with interactive Architecture Modal inspector.
- **Featured Repositories**:
  - `url-shortener-api`: FastAPI & Redis high-throughput URL shortener with analytics.
  - `travel-data-scraper`: Asynchronous Playwright web scraper with anti-detection.
  - `job-application-tracker-api`: Enterprise FastAPI & PostgreSQL recruitment management API.
  - `house-prices-regression`: End-to-end Machine Learning regression stacking pipeline.
  - `FoodOrderingApp`: Full-stack food delivery application with reactive cart state.
  - `deforestation-project`: Geospatial ML & computer vision satellite analysis pipeline.
  - `customer-churn-prediction`: Predictive churn analytics with XGBoost & SHAP explainability.
  - `shopping-app`: Responsive modern e-commerce storefront.
- **Skills Matrix**: Categorized proficiency matrix with animated scroll-triggered progress bars.
- **Career & Education Timeline**: Interactive tabbed journey through experience, degrees, and certifications.
- **Working Contact Form**: Real-time client validation, localStorage message tracking, and toast notifications.
- **Design System**: Dark / Light mode toggle with memory persistence, glassmorphism UI, and fluid mobile drawer.

## 💻 Quick Start Locally

### Option 1: Run with Python Server
```bash
python server.py
```
Visit `http://localhost:8000` in your web browser.

### Option 2: Run with NPM
```bash
npm start
```

---

## 🧪 Running Automated Tests

Run the Python unit & validation test suite:
```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

Run the Node.js project schema test:
```bash
node tests/test_projects_data.js
```
